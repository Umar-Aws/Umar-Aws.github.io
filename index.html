03 / Featured project

AWS Cloud Infrastructure Lab.

A practical learning project covering foundational AWS infrastructure components and their configuration.

Core AWS infrastructure and services

Created a custom VPC, deployed a Linux EC2 instance in the public subnet, worked with additional EBS storage, practiced S3 object controls, and configured IAM identities and policies.

Completed · Lab cleaned up

What was implemented

  • Custom VPC with public and private subnets.
  • Internet Gateway and public route configuration.
  • Linux EC2 instance accessed over SSH.
  • Additional EBS volume, mount, and snapshot.
  • S3 versioning, lifecycle, and presigned URL practice.
  • IAM users, groups, roles, and policies.
  • Separate S3 static website hosting exercise.
